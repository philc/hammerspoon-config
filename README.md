# hammerspoon-config

This is my [Hammerspoon](http://www.hammerspoon.org/) config. I used it heavily from Nov 2017 - Jan 2023, and
have since switched to [Phoenix](https://github.com/kasper/phoenix/) for most things; here's my
[config](https://github.com/philc/phoenix-config).

What remains here:

- `vim.lua`: vim-style normal and visual modes for text editing in any app, toggled by tapping right-Cmd
  (which Karabiner maps to F17).
- `init.lua`: makes Cmd-V paste clipboard images in terminals, for Claude Code and Pi.
